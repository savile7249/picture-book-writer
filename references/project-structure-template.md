# 绘本项目持久化工作台规范 (Story Bible)

针对系列绘本（Multi-Volume Picture Books）与长期 IP 项目，推荐在本地建立持久化工作台目录。

---

## 一、 标准工作台目录树
```
My-Picture-Book-Series/
├── 设定/
│   ├── 主角档案.md                  # 主角常态造型、性格弱点、情绪微动作、禁忌
│   ├── 伴侣角色.md                  # 伴侣动物/玩具外观、体型比例、说话口头禅
│   ├── 世界观与场景.md              # 故事常驻场景地图、自然探索安全边界
│   └── 文风与口诀.md                # 系列核心复沓口诀、词汇表、单页留白规范
├── 大纲/
│   ├── 第01册_分镜细纲.md           # 画面01~32的核心动作与情绪曲线
│   └── 第02册_分镜细纲.md
├── 脚本/
│   ├── 第01册_完整图文分镜版.md     # 供插画师出图与排版
│   └── 第01册_语音克隆纯台词版.txt  # 供声音克隆软件直接合成
└── 追踪/
    ├── IP道具资产表.md              # 跨册出现的固定道具（观察包、围巾等）
    └── 故事创作记录.md              # 创作进展、时长与录音状态
```

## 二、 跨册一致性维护规则
1. **主角外貌不可漂移**：主角服装、发型与伴侣动物体型在各册中保持一致。
2. **安全边界永不妥协**：不论哪一册，绝不出现进入深水、攀爬高处或吞食野生植物等危险行为。
3. **成长弧线单向递进**：主角在上一册学到的技能或情感接纳，在后续册中作为默认背景，不再重复退化。

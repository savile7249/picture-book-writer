# IP 覆盖示例

本文件只展示可提交的系列连续性信息。调用方应把这些内容转换为 `CreationBriefV1` 字段；Skill 不自动读取目录或写入文件。

## 系列信息

- `storyBibleVersion`：`series-demo-1`
- 世界范围：安静的家庭空间、庭院和有人陪同的自然观察径
- 固定边界：不进入深水，不攀爬高处，不采食未知植物

## 常驻角色 1

- `id`：`child-1`
- 姓名：由客户提供的非敏感昵称
- 角色：主角
- 外观：短深色头发、圆润温和的面部特征、学龄前儿童比例
- 固定服装：由所选画风锚点决定
- 固定道具：一个无文字、无品牌的观察包
- 连续性提示：紧张时轻轻捏住背带；好奇时身体略向前倾

## 常驻角色 2

- `id`：`companion-1`
- 姓名：原创伙伴名称
- 角色：陪伴角色
- 外观：明确物种、颜色、体型比例和识别特征
- 固定道具：最多一个
- 连续性提示：不得跨页改变体型、颜色或固定道具

如需第三个常驻角色，使用相同字段。不得超过 3 个；临时背景人物不写入系列连续性锚点。

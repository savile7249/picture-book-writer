# Picture Book Writer Skill (`picture-book-writer`)

专为 **“AI 父母语音克隆 + 有声绘本”** 交付场景打造的工业化儿童绘本分镜脚本创作工具。

## 目录结构
```
picture-book-writer/
├── SKILL.md                                  # 核心技能入口与工业化创作管线
├── README.md                                 # 本说明文档
└── references/
    ├── classic-picture-books.md              # 经典爆款绘本拆解对标库
    ├── picture-book-deslop.md                # 绘本去 AI 味与儿童语感清洗指南
    ├── project-structure-template.md         # 系列绘本持久化 Story Bible 模板
    └── ip-overrides-example.md               # IP 角色与世界观覆盖文件模板
```

## 核心亮点
1. **分阶段纲要门禁（Outline Gate）**：强制先出分镜细纲与情绪曲线，确认后再展开正文，杜绝篇幅与逻辑跑偏。
2. **深度去 AI 味（Deslop）**：内置儿童文学专项清洗词表，杜绝成人说教与假大空总结。
3. **经典爆款对标**：内置《猜猜我有多爱你》《好饿的毛毛虫》《野兽国》等叙事节奏与复沓钩子拆解。
4. **双版本交付**：同时输出供画师的“图文分镜版”与供语音克隆软件的“纯文本台词版”。
5. **持久化 Story Bible**：支持多册系列绘本的跨册设定、道具与成长线一致性维护。
